# AI Usage

## Propósito

Este documento describe cómo utilicé Inteligencia Artificial (IA) como apoyo durante el desarrollo del proyecto, qué tareas me ayudó a acelerar y qué decisiones quedaron bajo mi criterio.

## Cómo Usé La IA En Este Proyecto

Usé IA principalmente como asistente técnico para:

- Estructurar el proyecto con una organización moderna de Next.js orientada por features.
- Implementar y refinar componentes, hooks, servicios y estado global.
- Aplicar y ajustar decisiones de arquitectura (por ejemplo, separación entre `app/` y `src/features/`).
- Integrar y validar librerías clave del stack (`React Query`, `Redux Toolkit`, `Zod`, `Tailwind`, `Playwright`, `Vitest`).
- Corregir errores de tipado/lint y mejorar consistencia del código.
- Diseñar y estabilizar pruebas críticas (smoke tests y validaciones E2E).
- Redactar y mejorar documentación técnica (`README`, `DECISIONS`, documento de arquitectura bancaria).

## Apoyo Específico Que Recibí

La IA me ayudó de forma práctica en estos puntos:

1. **Implementación técnica**
- Ajustar flujos de login, dashboard y transferencias.
- Mejorar el manejo de estado local/global y server state simulado.
- Resolver inconsistencias entre mocks, UI y tests.

2. **Calidad y testing**
- Crear y ajustar smoke tests para flujos críticos.
- Corregir problemas de configuración y compatibilidad en testing/build.
- Verificar que lint, unit tests, build y smoke tests quedaran en verde.


## Decisiones Que Mantuve Como Autor Del Proyecto

Aunque utilicé IA como apoyo, las decisiones finales fueron mías, especialmente en:

- Definir el alcance funcional del challenge.
- Elegir qué arquitectura era adecuada para este contexto (sin sobreingeniería).
- Definir librerias y herramientas de entorno.
- Priorizar qué problemas corregir primero.
- Validar que los cambios reflejaran la intención del proyecto.

## Límites Del Uso De IA

La IA se utilizó como herramienta de aceleración y revisión técnica, no como reemplazo de criterio de ingeniería. Todo cambio relevante fue revisado y contextualizado dentro de los objetivos del proyecto.

## Resultado

El uso de IA permitió avanzar más rápido en implementación, limpieza técnica y documentación, manteniendo el control de las decisiones de arquitectura y de producto.
